# Implement Issue

Use this skill whenever implementing a GitHub issue.

## Instructions

1. Read:
    - docs/product.md
    - docs/architecture.md
    - docs/coding-standards.md

2. Analyze the issue requirements.

3. Create an implementation plan.

4. Identify:
    - impacted entities
    - impacted API endpoints
    - impacted frontend pages
    - required tests

5. Implement following project standards.

6. Run tests.

7. Summarize the changes.
